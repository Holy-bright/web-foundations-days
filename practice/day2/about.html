About QuickNotes

QuickNotes is a simple, fast note-taking app that helps you capture ideas before they slip away. It runs entirely in your browser with no sign-up required.

How to use QuickNotes

  1. Type your note into the text box at the top of the page.
  2. Press Enter or click the Add Note button to save it.
  3. Click a note to edit it, or click Delete to remove it.

Features

  • Add notes instantly with a single key press
  • All notes saved in your browser automatically
  • Works offline — no internet connection needed
  • Clean, distraction-free interface

Keyboard shortcuts

Shortcut Action
Enter Add the note
Ctrl + S Save the file in VS Code
Escape Cancel editing
